Legend

Palette
OKLCH paper ramp from archival cotton paper, manila folders, and red editor proof marks under warm desk light. The dark override keeps the same material direction with lower lightness and the same warm bias.
Type scale
Plex Local handles interface chrome at 22, 16, 13, and 12px. JetBrains Local handles artifact identifiers, counts, versions, timestamps, keyboard hints, and code. Source Serif Local handles review comments and report prose.
Spacing and shape
Spacing uses 4, 8, 12, 16, and 24px steps. Data tables and artifact frames use 2px corners, controls use 4px corners, and temporary overlays would use 7px. Borders separate planes without decorative depth.
Icons
Phosphor regular SVGs are inlined from the local asset set. Artifact type and status icons are paired with visible labels and border styles, so state survives grayscale and color vision deficiency.
